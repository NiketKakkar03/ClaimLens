# Build locally before validating the cloud deployment

The project teaches ML engineering and platform operations without personal expenditure. Complete the data-to-prediction workflow locally using synthetic data, Spark/Delta, MLflow, a prediction API, and service metrics before introducing cloud infrastructure. Later required releases add local Kubernetes operations, Databricks platform evidence, cloud infrastructure evidence, reliability and recovery, governed GenAI, and portfolio documentation.

Use local Kubernetes for repeatable operational experiments. Real AWS deployments are short-lived validation exercises using the already tested artifacts and require verified active credits, a reviewed cost estimate, and a same-day teardown plan. Do not deploy when personal charges cannot be confidently avoided. Document any cloud capability that remains unexecuted rather than claiming that a local substitute proves real AWS operation.

This sacrifices continuous managed-cloud operation in exchange for reproducibility and cost control. Post-MVP capabilities remain required roadmap work; credit or service limitations must be recorded as unresolved delivery constraints.
